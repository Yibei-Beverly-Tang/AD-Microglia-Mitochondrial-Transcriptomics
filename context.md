# Source literature and project scope

The project was defined from six papers in the original working folder. The papers provide biological context; they do not determine the results reported here.

| Source file | Use in this project |
| --- | --- |
| A Unique Microglia Type Associated with Restricting Development of Alzheimer's Disease.pdf | Establishes disease-associated microglia as a distinct AD-related state. |
| Single cell RNA sequencing of microglia throughout the mouse lifespan and in the injured brain reveals complex cell-state changes.pdf | Shows that age and injury alter microglial state composition. |
| Lipid-droplet-accumulating microglia represent a dysfunctional and proinflammatory state in the aging brain.pdf | Motivates analysis of lipid processing, phagocytosis, ROS, and inflammatory modules. |
| s41586-024-07185-7.pdf | Links APOE4/4 to lipid-droplet accumulation and damaging microglial states. |
| 10.1016:j.cell.2023.08.037.pdf | Provides the human AD microglial state and disease-progression context related to GSE227223. |
| s41586-024-07606-7.pdf | Supports region-aware and cell-state-aware analysis of human AD tissue. |

The resulting analysis question is:

> Do mitochondrial-encoded transcript features differ across non-AD, early-AD, and late-AD microglia in a public human single-nucleus RNA-seq dataset?

The analysis is an extension of the literature context. It does not reproduce the original papers' main claims. The current data support transcript-level comparisons, not mtDNA mutation, heteroplasmy, copy-number, or causal inference.

The PDF files are not redistributed in this repository. Their filenames and roles are recorded here so that readers can retrieve and cite the original sources.
