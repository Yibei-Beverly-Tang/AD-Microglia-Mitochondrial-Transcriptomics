# Planned analyses

## Data checks

- Confirm the interpretation of the released seurat_clusters.
- Compare donor, brain-region, and disease-group distributions.
- Identify low-quality cells and donors that dominate group-level summaries.

## Statistical validation

1. Aggregate raw counts by donor, brain region, and cell state.
2. Run donor-aware pseudobulk differential expression.
3. Report effect sizes, confidence intervals, and adjusted p values.
4. Compare mitochondrial-encoded genes, nuclear-encoded mitochondrial genes, and percent.mt.
5. Test sensitivity to age, sex, brain region, sequencing batch, and cell-state composition.
6. Replicate the analysis in an independent dataset.

This file describes planned work. It does not describe completed analyses.
